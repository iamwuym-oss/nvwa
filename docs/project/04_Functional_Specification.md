# Nüwa Backup 功能规范文档

**版本：** v2.1（经专家审查修正）
**日期：** 2026-07-05
**状态：** 范围已收敛 — 本文档记录产品终局功能规范，当前开发阶段仅实现标记为 Phase 1 的内容

---

## 范围声明

本文档描述 Nüwa Backup 产品的**完整终局功能规范**。所有功能已与产品需求方逐项确认。

**重要：** 本文档中的功能分为多个开发阶段实现。当前开发阶段（Phase 1）仅包含文件级完整备份/恢复的最小闭环。

| 标记 | 含义 |
|------|------|
| ✅ Phase 1 | 当前 MVP 阶段实现 |
| 🔵 Phase 2 | 可用文件备份阶段实现 |
| 🔵 Phase 3 | NTFS 非系统卷镜像阶段实现 |
| 🔵 Phase 4+ | 系统恢复与高级功能阶段实现 |
| 🔵 Future | 后续阶段（Phase 5+）实现 |

Phase 1 的具体范围和任务详见 `02_Development_Plan.md` 和 `09_MVP_Boundary_and_Risk_Correction.md`。

## 1. 备份功能

### 1.1 备份类型

| 特性 | 规范 | 阶段 |
|------|------|------|
| 完整备份 (Full) | **支持**。首次备份和用户指定时间点的完整快照 | ✅ Phase 1 |
| 差异备份 (Differential) | **支持**。基于最近一次完整备份，记录自上次完整备份以来的所有变化 | 🔵 Future (Phase 5+) |
| 增量备份 (Incremental) | **不支持**。增量链的依赖关系过于复杂，不采用 | ❌ 永久排除 |
| 持续备份 (Continuous/Always-On) | **不支持**。仅做定时任务触发的备份，不做实时文件监控 | ❌ 永久排除 |
| 调度触发 | 用户按每月、每周、每天、每小时选择备份策略，包括完整和差异备份 | 🔵 Phase 2+ |

### 1.2 备份源

| 特性 | 规范 | 阶段 |
|------|------|------|
| 文件/文件夹级备份 | **支持**。用户可逐个选择文件和文件夹 | ✅ Phase 1 |
| 卷级备份 | **支持**。用户可选择单个卷或多个卷 | 🔵 Phase 3 |
| 磁盘级备份 | **支持**。用户可选择整个磁盘（包含所有分区） | 🔵 Phase 4+ |
| 启动分区 | **全部包含**。EFI System Partition、MSR、Windows Recovery Partition、OEM 恢复分区均在备份范围内 | 🔵 Phase 3 |
| 动态磁盘 | **支持**单磁盘模式下的动态磁盘 | 🔵 Phase 3 |
| 操作系统 RAID | **支持** | 🔵 Phase 3 |
| 硬件 RAID | **支持** | 🔵 Phase 3 |
| 跨区卷 (Spanned Volume) | **支持**（由底层块设备机制自然处理） | 🔵 Phase 3 |
| 非 Windows 分区 | **备份所有已分配块**。无论分区是 Windows 的 NTFS/FAT32 还是 Linux 的 ext4/XFS，已分配的磁盘块全部备份，未分配的跳过。通过块级感知机制统一处理 | 🔵 Future (Phase 5+) |
| 非 Windows 的已分配空间 | **识别并备份**。块级引擎通过文件系统感知机制区分已分配/空闲空间 | 🔵 Future (Phase 5+) |
| USB 设备作为备份源 | **支持** | ✅ Phase 1 (文件级) / 🔵 Phase 3 (卷级) |

### 1.3 备份目标

| 特性 | 规范 | 阶段 |
|------|------|------|
| 本地第二块硬盘 | **支持**（内置副盘） | ✅ Phase 1 |
| USB 外置硬盘/SSD | **支持** | ✅ Phase 1 |
| NAS / SMB 共享文件夹 | **支持**（CIFS 协议） | 🔵 Phase 2 |
| 本机同一个磁盘 | **支持**（备份到同一物理磁盘的不同分区） | 🔵 Phase 2 |
| 多个目标 | **不支持**。一个备份任务只写入一个目标位置 | ❌ 永久排除 |
| USB 作为目标 | **支持**。自动创建 Nüwa Backup 专用目录结构 | ✅ Phase 1 |
| 网络目标地址输入 | **支持**手动输入共享路径并浏览网络邻居 | 🔵 Phase 2 |
| SMB 凭据管理 | 手动输入用户名和密码并保存在本地，NAS 密码变更后提示用户重新输入 | 🔵 Phase 2 |
| NFS 挂载 | **支持** | 🔵 Future (Phase 5+) |

### 1.4 调度

| 特性 | 规范 | 阶段 |
|------|------|------|
| 一次性 | **支持** | 🔵 Phase 2 |
| 每日（每天 HH:MM） | **支持** | 🔵 Phase 2 |
| 每周（选中某几天） | **支持** | 🔵 Phase 2 |
| 每月（每月第 X 天） | **支持** | 🔵 Phase 2 |
| 系统启动时 | **支持** | 🔵 Phase 3 |
| 用户登录时 | **支持** | 🔵 Phase 3 |
| 插入指定 USB 设备 | **支持**（USB 事件触发） | 🔵 Phase 3 |
| 组合调度策略 | **支持**。用户可按月/周/天/小时的维度自由组合完整备份和差异备份 | 🔵 Phase 2+ |

### 1.5 保留策略

| 特性 | 规范 | 阶段 |
|------|------|------|
| 保留最近的 N 个完整备份 | **支持**。用户设定保留多少个完整备份 | 🔵 Phase 2 |
| 依赖感知 | 如果差异备份依赖的某个完整备份需要被删除，则推迟删除 | 🔵 Future (Phase 5+) |
| 事前空间检测 | 备份任务发起前预估所需空间，空间不足则取消并提示用户 | ✅ Phase 1 |
| 自动清理 | 达到保留上限后，自动清理最旧的、无依赖的完整备份 | 🔵 Phase 2 |

## 2. 恢复功能

### 2.1 文件级恢复

| 特性 | 规范 | 阶段 |
|------|------|------|
| 浏览备份内容 | **支持**。树形结构浏览备份中的文件和文件夹 | ✅ Phase 1 |
| 搜索备份内容 | **支持**。按文件名搜索已备份的文件 | 🔵 Phase 2 |
| 恢复到原位置 | **支持** | ✅ Phase 1 |
| 恢复到新位置 | **支持** | ✅ Phase 1 |
| 恢复并改名 | **支持** | ✅ Phase 1 |

### 2.2 卷级恢复

| 特性 | 规范 | 阶段 |
|------|------|------|
| 恢复到原卷（覆盖） | **支持** | 🔵 Phase 3 |
| 恢复到不同卷 | **支持** | 🔵 Phase 3 |
| 恢复到更大目标盘 | **支持**，自动扩展最后一个分区到目标盘末端 | 🔵 Phase 3 |
| 恢复到更小目标盘 | **条件支持**。如果已用空间 ≤ 目标盘容量，自动缩容；如果超过，阻止并提示 | 🔵 Phase 3 |
| 恢复前安全检查 | 目标卷所有数据将被永久覆盖，必须明确确认 | 🔵 Phase 3 |
| 恢复后引导修复 | 自动检测并修复 Windows 引导（BCD） | 🔵 Phase 4+ |

### 2.3 裸机恢复

| 特性 | 规范 | 阶段 |
|------|------|------|
| 引导介质启动 | 使用 WinPE 或 Linux 引导介质启动计算机 | 🔵 Phase 4+ |
| 自动发现备份 | 自动扫描本地磁盘和 USB 设备上的备份文件 | 🔵 Phase 4+ |
| 网络备份定位 | 用户手动输入 SMB/NFS 路径访问网络上的备份 | 🔵 Phase 4+ |
| 手动指定备份 | 用户浏览并选择要恢复的备份文件 | 🔵 Phase 4+ |
| 引导修复 | 恢复完成后自动修复系统引导 | 🔵 Phase 4+ |

### 2.4 异机还原 (Universal Restore)

| 特性 | 规范 | 阶段 |
|------|------|------|
| 恢复至不同硬件 | **支持**。系统恢复到硬件配置不同的机器上（主板、CPU、磁盘控制器不同） | 🔵 Future (Phase 5+) |
| 驱动注入 | 在恢复过程中注入目标硬件所需的驱动 | 🔵 Future (Phase 5+) |

## 3. 磁盘克隆

### 3.1 克隆模式

| 特性 | 规范 | 阶段 |
|------|------|------|
| 磁盘 → 磁盘 | **支持**。直接克隆源磁盘到目标磁盘 | 🔵 Phase 5 |
| 磁盘 → 文件 | **支持**。先备份为镜像文件，稍后恢复 | 🔵 Phase 5 |
| 作为独立功能 | **支持**。在管理界面中作为独立功能入口，但内部复用备份/恢复引擎 | 🔵 Phase 5 |

### 3.2 克隆安全

| 特性 | 规范 | 阶段 |
|------|------|------|
| 克隆到更小磁盘 | **条件支持**。已用空间 ≤ 目标容量则自动缩容，超过则阻止 | 🔵 Phase 5 |
| 目标盘确认 | 多重确认：目标磁盘所有数据将永久覆盖 | 🔵 Phase 5 |
| 禁止自我克隆 | 源磁盘 ≠ 目标磁盘 | 🔵 Phase 5 |

## 5. 验证

| 特性 | 规范 | 阶段 |
|------|------|------|
| 自动验证（备份完成后） | **支持**。完成后立即校验 | ✅ Phase 1 (SHA-256 文件级) |
| 定期验证（计划任务） | **支持**。用户可配置周期自动验证 | 🔵 Phase 2 |
| 手动验证 | **支持**。用户随时触发 | ✅ Phase 1 |
| 校验级别 | 文件级 SHA-256（Phase 1）；块级 xxHash3（Phase 3+） | ✅ Phase 1 (文件级) |
| 发现损坏后的行为 | (1) 发出告警通知 → (2) 自动尝试深度修复 → (3) 修复失败则提示用户重新创建备份 | 🔵 Phase 2+ |

---

## 6. 加密

| 特性 | 规范 | 阶段 |
|------|------|------|
| 默认状态 | **不加密**。不影响备份速度 | ✅ Phase 1 |
| 用户可选 | **支持**。用户可对单个备份任务启用加密 | 🔵 Future (Phase 5+) |
| 加密算法 | AES-256（后续扩展国密 SM4 作为信创版选项） | 🔵 Future (Phase 5+) |
| 密码丢失 | **数据不可恢复**。不设密码找回机制 | 🔵 Future (Phase 5+) |
