## Phase 1：MVP — 文件级备份/恢复 CLI（当前阶段）

### 核心原则

- 恢复验证优先于备份完成
- 数据完整性高于备份速度
- 先闭环，再扩展

### 1.1 项目基础

| # | 功能 | Allowed Now | 验收标准 | 恢复验证 | 风险 |

## 当前 Phase 1 禁止实现清单

以下功能在 Phase 1（MVP）阶段严禁实现：

| 功能 | 理由 | 计划阶段 |
|------|------|---------|
| 差异备份 (Differential) | USN Journal + 块映射过于复杂 | Phase 5+ |
| .nwb 镜像格式 | 格式设计过早复杂化 | Phase 2 实验 / Phase 3 正式 |
| XOR Parity / Erasure Coding | 增加实现复杂度 | Phase 5+ |
| AES 加密 | MVP 不处理敏感数据场景 | Phase 5+ |
| VSS 快照 | Phase 1 不需要系统卷一致性 | Phase 3 |
| 卷级/磁盘级备份 | Phase 1 仅文件级 | Phase 3 |
| GPT/MBR 分区表 | 文件级不需要分区解析 | Phase 3 |
| 启动分区识别 | 文件级不需要启动分区 | Phase 3 |
| WinPE / 启动介质 | 不需要裸机恢复能力 | Phase 4 |
| 裸机恢复 | 不需要 | Phase 4 |
| 异机还原 | 不需要 | Phase 5+ |
| 驱动注入 | 不需要 | Phase 5+ |
| 磁盘克隆 | 不需要 | Phase 5 |
| lcb-daemon 系统服务 | CLI 直连即可 | Phase 3 |
| Desktop GUI (Tauri 2.0 + React + TypeScript) | 命令行即可完成 MVP | Phase 2 后期 |
| NFS 支持 | 网络存储场景复杂 | Phase 5+ |
| SMTP 邮件通知 | MVP 不需要远程通知 | Phase 2 |
| Linux / 国产 OS | 跨平台后置 | Phase 5+ |
| BitLocker / ReFS | 不处理加密文件系统 | Phase 5+ |
| ext4 / XFS / btrfs 智能识别 | 非 Windows 后置 | Phase 5+ |
| 性能优化目标（500MB/s） | 正确性优先 | Phase 4+ |
